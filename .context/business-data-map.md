## 1. Executive Summary

### What does this system do?

The system is a high-performance, single-page professional web platform hosted on GitHub Pages (`marttinroman.github.io`). It solves the conversion bottleneck for senior engineering talent by providing verifiable, interactive proof of technical depth in Senior QA Automation, SDET, and AI-TestOps. 

Instead of relying on static text claims or standard resumes, the platform demonstrates real engineering rigor through:
1. An adaptive, bilingual client interface (English default, instant Spanish toggle) with Dark/Light mode theme switching.
2. A prominent architectural showcase of the **Autonomous QA & AI-TestOps Engine** (covering Web UI, API schemas, and non-deterministic LLM/RAG evaluation).
3. Direct navigation to active, open-source repositories on GitHub with zero ongoing infrastructure costs ($0/month).

### Value Proposition

## 3. Business Flows

### Flow 1: Landing & First-Impression Discovery Flow

```
[Visitor lands on marttinroman.github.io]
       |
       v
[Head script resolves 'preferred_theme' or OS preference] --> [Applies .dark class]
       |
       v
[i18n engine resolves 'preferred_locale' or defaults to 'en'] --> [Injects copy]
       |
       v
[Hero renders: Title, Bio, Availability Badge, Avatar]
```

**Business Rules:**
- First visit MUST default to English to cater to international recruiters.
- Theme detection MUST execute prior to first paint to prevent visual flash (FOUC).
- If GitHub avatar fails to load, client MUST gracefully fall back to local/initials avatar.
