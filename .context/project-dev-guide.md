## 2. Core Architectural Principles

```
                   +---------------------------------------+
                   |           index.html (Root)           |
                   +---+-------------------------------+---+
                       |                               |
       Styling & Theme |                               | i18n & Logic
                       v                               v
            Tailwind CSS (CDN)              Native Vanilla JS
          + Class-Based Dark Mode         + Dictionary Translations
          + FOUC Prevention Script        + LocalStorage Persistence
```

1. **Zero Framework Bloat:** There is no heavy framework runtime (no React, Next.js, or Vue hydration overhead). The core application lives in [index.html](file:///Users/marttinroman/projects/2026/portfolios/marttinroman.github.io/index.html). Keep it clean, semantic, and blazingly fast.
2. **Zero Infrastructure Cost ($0 Overhead):** Everything must deploy statically to GitHub Pages. Do not introduce backend servers, node daemons, or paid cloud databases for the core portfolio.
3. **Bilingual Symmetry:** Every new UI feature, text badge, or button must have symmetrical entries in both `translations.en` and `translations.es`. English is always the first-class international default.
4. **Theme Contrast Compliance:** Both Dark Mode (`slate-950` with `sky-400` accents) and Light Mode (`slate-50` with `slate-900` text) must strictly meet WCAG 2.1 AA contrast requirements ($\ge 4.5:1$).

## 3. What to Consider When Working on Each Area

### A. Updating Profile & Media
- The primary professional headshot is located at `docs/img/LinkedIn.jpeg`.
- Always verify that the `onerror` fallback (`https://ui-avatars.com/...`) remains intact.
- If you add new images, store them in `docs/img/` and use relative paths so they resolve correctly on GitHub Pages and custom domains alike.

### B. Adding or Modifying Project Cards
- Each card in the Featured Projects section follows a standardized structure:
  - Header badge / icon
  - Title with `data-i18n="projX_title"`
  - Description with `data-i18n="projX_desc"`
  - Footer with tech stack tag and an outbound link (`target="_blank" rel="noopener noreferrer"`).
- When adding a new project:
  1. Add the HTML markup in [index.html](file:///Users/marttinroman/projects/2026/portfolios/marttinroman.github.io/index.html).
  2. Add the corresponding keys to both `translations.en` and `translations.es`.
  3. Ensure the outbound link points to an active, well-documented repository on GitHub.

### C. Theming & Avoiding FOUC
- Notice the inline script at the top of the `<head>`. It checks `localStorage` and `prefers-color-scheme` before the body renders.
- Never move or delay this script. Without it, users on dark mode will experience a blinding white flash on page load.
- If you add custom CSS utility classes, ensure they have corresponding `dark:...` variants.

### D. Contact Channels
- The direct contact button uses a pre-configured `mailto:` with subject line encoding.
- The "Copy Email" button triggers a custom floating toast. When modifying the toast, keep its transition classes (`translate-y-20`, `opacity-0`) synchronized with the timeout in the JavaScript helper (currently 2500ms).

### E. Video Assets & Media Pipeline
- Executive and presentation videos are managed according to the standard operating procedure documented in [`.context/guidelines/DEV/video-asset-pipeline.md`](file:///Users/marttinroman/projects/2026/portfolios/marttinroman.github.io/.context/guidelines/DEV/video-asset-pipeline.md).
- Use the automated processing script:
  ```bash
  # Ingest and optimize raw video (web-safe slug, moov faststart, poster frame extraction, symlink)
  bash scripts/process-video.sh "/path/to/raw-video.mp4" [optional-slug]
  # Or via npm/bun script
  bun run video:process "/path/to/raw-video.mp4" [optional-slug]
  ```
- Always verify the 4 core conditions:
  1. Autoplaying (`autoplay`, `loop`, `muted`, `playsinline`).
  2. Floating `#video-unmute-overlay` sound toggle gesture.
  3. Optimized web streaming format (`-movflags +faststart` with H.264/AAC).
  4. Instant poster preview image (`docs/img/video-poster.jpg`).
