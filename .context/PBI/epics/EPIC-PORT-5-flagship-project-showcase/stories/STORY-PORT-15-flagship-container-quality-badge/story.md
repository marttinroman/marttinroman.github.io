## User Story

**As an** engineering director or technical recruiter,  
**I want to** see a highlighted flagship project card with distinct visual styling and production badges,  
**So that** I immediately understand Marttin's marquee achievement in Autonomous QA and AI-driven testing.

### In Scope
- Elevated flagship container in `#projects`.
- Badge: "Production Ready / Autonomous AI-TestOps Engine".

- Direct link to `https://github.com/marttinroman/autonomous-qa-engine`.

### Out of Scope
- Interactive embedded code editors in MVP.
