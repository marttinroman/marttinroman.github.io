# Technical Specialties & Competence Mapping

**Jira Key:** PORT-4
**Status:** DONE
**Priority:** MEDIUM
**Phase:** Core Presentation

---

## Epic Description

Structures Marttin's technical competencies into 3 primary domains:
1. **Autonomous TestOps & AI Pipelines** (Agentic AI, Self-healing suites, CI/CD).
2. **End-to-End Automation Frameworks** (Playwright, Cypress, KATA architecture).
3. **API Contracts & Performance Engineering** (OpenAPI, k6, Postman, Contract testing).
Accompanied by a curated tool cloud (TypeScript, Python, Docker, GitHub Actions, Vitest).

**Business Value:**
Allows technical screeners to quickly map candidate skills to job requirements and open positions.

---

## User Stories

1. **PORT-12** - As a technical screener, I want a 3-column specialties grid so that I can see the breadth of Marttin's technical mastery.
2. **PORT-13** - As an international recruiter, I want the specialties copy to translate dynamically so that I can evaluate capabilities in my preferred language.
3. **PORT-14** - As an engineering lead, I want to see categorized tools and frameworks badges so that I can confirm stack compatibility.
