### Flow 1: Theme Engine & Visual Verification
- **What to test:**
  1. Default theme matching OS preference (`prefers-color-scheme: dark` vs `light`).
  2. Manual theme toggling via `#theme-toggle`.
  3. Theme persistence across page reloads in `localStorage` under key `preferred_theme`.
  4. Absence of FOUC (Flash of Unstyled Content) on hard reload.
- **Why it matters:** Technical hiring managers often use dark mode developer setups. An awkward theme flash or broken light-mode text contrast immediately signals lack of attention to detail.
- **Edge cases to watch for:**
  - Private browsing / incognito modes where `localStorage` might throw security exceptions.
  - Text legibility in light mode (verify contrast ratio $\ge 4.5:1$).

---

### Flow 2: Bilingual Translation (i18n) & Layout Stability
- **What to test:**
  1. Default loading in **English** on first clean session.
  2. Instant translation to **Spanish** upon clicking `#lang-toggle` without a full page reload.
  3. 100% key coverage: verify that NO element retains English when Spanish is active and vice versa (check all 38 keys).
  4. Layout integrity: Spanish text is typically ~15-20% longer than English. Verify that no card buttons clip or wrap awkwardly.
- **Why it matters:** The portfolio serves both US/global recruiters and regional LatAm founders. Incomplete translations look unprofessional.
- **Edge cases to watch for:**
  - Elements dynamically updated via JS that might miss translation bindings.
  - Viewport widths between 320px and 375px where long Spanish words might cause horizontal scroll.

### Flow 3: Outbound Link Integrity & Security
- **What to test:**
  1. All 5 repository links must return HTTP 200:
     - `autonomous-qa-engine`
     - `e2e-framework-boilerplate`
     - `ai-vector-validation-suite`
     - `api-performance-harness`
     - `visual-regression-engine`
  2. External social links (GitHub profile and LinkedIn).
  3. Every external link (`target="_blank"`) MUST have `rel="noopener noreferrer"`.
- **Why it matters:** A single `404 Not Found` when a recruiter clicks "Inspect Repository" ruins the entire conversion opportunity.

---

### Flow 4: Contact & Conversion Mechanisms
- **What to test:**
  1. Click on "Contact" triggers a `mailto:` link with pre-populated recipient (`marttinroman@gmail.com`) and encoded subject.
  2. Click on "Copy Email" copies the address to the system clipboard and displays the visual toast message for ~2.5 seconds before fading out.
  3. Repeated rapid clicks on the copy button must not trigger timer glitches or permanent toast stuck state.
- **Why it matters:** Friction in contacting the candidate directly reduces recruiter conversion rates.
