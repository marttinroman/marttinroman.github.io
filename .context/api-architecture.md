## 2. Data Endpoints & Client Contracts

### Contract 1: Developer Profile & Metadata

```
GET /data/profile.json
```
- **Description:** Returns primary author details, professional title, and availability status.
- **Sample Response:**
```json
{
  "name": "Marttin Roman",
  "title": {
```

### Contract 2: Project Showcase Catalog

```
GET /data/projects.json
```
- **Description:** Returns the catalog of featured repositories.
- **Projects Included:**
  1. `autonomous-qa-engine` (Flagship)
  2. `e2e-framework-boilerplate`
  3. `ai-vector-validation-suite`
  4. `api-performance-harness`
  5. `visual-regression-engine`

---

### Contract 3: Localization Dictionaries

```
GET /data/locales/{locale}.json  (locale = "en" | "es")
```
- **Description:** Returns translation pairs for dynamic DOM text substitution.
- **Validation Rule:** All keys must exist identically in both language dictionaries to prevent layout clipping.
